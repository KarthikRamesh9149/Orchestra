# Security policy

Report suspected vulnerabilities privately to [hello@orchestraos.dev](mailto:hello@orchestraos.dev).
Do not post them in a public issue, pull request, or demo.

Please include:

- The app version or Git commit, operating system, and whether you used a local
  or shared workspace.
- The behavior, the affected permission or data boundary, and the impact.
- A minimal description using a disposable workspace and synthetic data.

Do not send API keys, session details, real project content, or database
backups. If a sensitive artifact is needed, ask the maintainer for a private
transfer channel before sharing it.

The source preview is not a signed public release and does not carry a support
SLA. See the [release scope](docs/desktop/release/README.md),
[threat model](docs/desktop/THREAT-MODEL.md), and
[verification and recovery handoff](docs/desktop/release/VERIFICATION.md).
For production service incidents, use your existing service support channel.
