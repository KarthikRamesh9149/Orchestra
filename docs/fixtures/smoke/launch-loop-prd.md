# Launch Loop PRD Fixture

## Product Goal
Orchestra helps client-facing software teams preserve a versioned understanding of what they are building.

## Reporting Requirement
Managers need a weekly reporting view that summarizes project health, unresolved client questions, current accepted scope, and pending review pressure.

## Dashboard Expectations
The project dashboard must show document readiness, Product Brain freshness, communication review pressure, and accepted change activity.

## Client-Safe Expectations
Clients can view shared documents and safe Product Brain summaries, but they must not see internal communication messages, connector metadata, internal proposals, or project operations internals.

## Truth-Gating
Original documents and original messages remain immutable source evidence. Communication intelligence can create review signals and proposals, but current truth changes only after manager acceptance.
